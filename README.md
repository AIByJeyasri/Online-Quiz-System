#  Online Quiz System

An interactive Online Quiz System that allows students to answer
multiple-choice questions and test their knowledge in an easy way.

- 🎯 Automatic score calculation
- 👨‍🎓 Student-friendly interface

- ⚡ Simple and easy to use
